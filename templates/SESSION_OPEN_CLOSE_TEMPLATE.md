# Session Open / Close Template

Use this when a project depends on continuity across sessions.

```md
=== OPEN | YYYY-MM-DD | Agent | CONFIDENCE: HIGH/MEDIUM/LOW ===
Context:
- Files read:
- Current mission:
- Scope:
- Known warnings:

YYYY-MM-DD | Agent | [short log line for completed action]

=== CLOSE | YYYY-MM-DD | Agent | ACTIVE_CONTEXT: updated/not updated ===
Completed:
- 

Files changed:
- 

Open items:
- 

Next action:
- 
```

Rule: the close block should make the next session easier to open.
